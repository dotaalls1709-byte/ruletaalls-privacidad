Política de privacidad de RuletaAlls

Última actualización: 25 de octubre de 2026

1. Información general

RuletaAlls es una aplicación gratuita de allsStore! que permite crear ruletas personalizadas y seleccionar opciones al azar.

2. Recopilación de datos

RuletaAlls no solicita cuentas de usuario ni está diseñada para enviar información personal al desarrollador. Las funciones principales se ejecutan localmente en el dispositivo.

3. Almacenamiento local

Las listas y preferencias pueden guardarse en el dispositivo para su uso posterior. No se sincronizan automáticamente entre dispositivos ni se almacenan en un servidor propio del desarrollador.

4. Compartir contenido

La aplicación puede permitir compartir ruletas mediante archivos o enlaces. El usuario debe revisar el contenido antes de compartirlo, ya que los destinatarios podrían acceder a la información incluida.

5. Servicios de terceros

RuletaAlls no está diseñada para vender datos personales. Los servicios externos utilizados por el sistema operativo o el entorno de ejecución pueden tener sus propias políticas de privacidad.

6. Seguridad y control del usuario

Los datos guardados localmente permanecen bajo el control del usuario y podrían perderse si se borran los datos de la aplicación o del dispositivo.

7. Cambios en esta política

Esta política podrá actualizarse si se incorporan funciones que modifiquen el tratamiento de la información.

8. Contacto

Para consultas sobre esta política, puedes contactar al desarrollador mediante el canal de soporte de RuletaAlls en Microsoft Store.
